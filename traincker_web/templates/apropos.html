Stack : Python, FastAPI, HTMX, pandas/numpy, matplotlib, API SNCF (Navitia), Supabase.

Architecture :

  • api_client.py — client HTTP vers l'API SNCF, avec timeout et gestion d'erreurs
  • monitor.py — surveillance périodique, alertes Discord/email, heures de silence
  • analysis.py / viz.py — statistiques de ponctualité et visualisations
  • traincker_web/ — interface FastAPI + HTMX (recherche, favoris, statistiques)
  • db.py — persistance partagée Supabase entre la surveillance et le site hébergé

Points notables : mode dégradé en cas de panne API, suite de tests automatisés (pytest), déploiement continu (GitHub Actions + Render).
